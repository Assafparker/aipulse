# AiPulse — ערכת נכסים

נכסים מקוריים שנוצרו עבור האתר. אין עליהם שאלת רישוי ואין צורך בקרדיט לצד שלישי.
כל הקבצים SVG וקטורי — נקיים בכל גודל, ומשנים צבע לבד לפי מצב בהיר/כהה של הדפדפן.

```
aipulse-mark.svg        סימן הלוגו, צבעוני, 64×64
aipulse-mark-mono.svg   אותו סימן ב-currentColor — להטמעה בתוך HTML בלבד
favicon.svg             גרסה מעובה לטאב ולסימנייה
hero.svg                גרפיקת פתיח, 1200×340
icons/*.svg             8 אייקוני משפחות מקור — לשימוש עם <img src>
icons-inline/*.svg      אותם אייקונים ב-currentColor — להדבקה בתוך ה-HTML
preview.html            דף ראווה של כל הערכה
```

## הרעיון מאחורי הסימן

הדשבורד כבר משתמש בדקדוק ויזואלי: עיגול מלא = מקור ראשוני, עיגול חלול = דיווח משני.
הסימן ממחזר בדיוק את זה — טבעת (הסריקה היומית) שבתוכה אות אחת נבחרת, ולצדה
נקודה אחת בחלודה: הפריט שסומן. הוא נשאר קריא גם ב-16 פיקסל.

הסימן ניטרלי לשפה — הוא גיאומטרי בלבד, בלי אותיות, ולכן עבד בלי שינוי במעבר
מ״מד״ן״ ל-AiPulse. את שם המותג מגדירים ב-HTML, לא בתוך ה-SVG.

## המלכודת שכדאי להכיר: currentColor לא חוצה `<img>`

קובץ SVG שנטען דרך `<img src="icon.svg">` הוא מסמך מבודד. הוא **לא** יורש את
`color` מהדף, ולכן `stroke="currentColor"` ייפול לשחור — מה שנראה סביר במצב בהיר
ונעלם לגמרי במצב כהה. בגלל זה יש כאן שתי תיקיות:

**`icons/`** — כל קובץ נושא צבע משלו עם `@media (prefers-color-scheme: dark)` פנימי:

```html
<img src="icons/journal.svg" width="24" height="24" alt="">
```

**`icons-inline/`** — `currentColor` נקי, יורש את צבע הטקסט מסביב:

```html
<span class="fam"><svg viewBox="0 0 24 24" ...>...</svg> כתבי עת שפוטים</span>
```
```css
.fam{ color: var(--accent-ink) }   /* האייקון יקבל את הצבע הזה */
```

לגרפיקת הפתיח ולסימן הצבעוני אין את הבעיה — הם מגדירים את הצבעים שלהם בפנים.

## גופנים והלוקאפ

Frank Ruhl Libre לכותרות, Heebo לטקסט, IBM Plex Mono למספרים ולתוויות —
שלושתם ב-Google Fonts, כמו בדשבורד. השם AiPulse מוגדר ב-HTML ב-Frank Ruhl
Libre 900 ולא כנתיבים בתוך ה-SVG, כך שאפשר לשנות אותו בלי לגעת בקבצים.

הדף כולו RTL, ולכן בלוקאפ הסימן יושב מימין והשם משמאלו. עטוף את השם עצמו
ב-`direction:ltr` כדי שסימני פיסוק צמודים לא ייזרקו לצד הלא נכון.

תת-הכותרת בדף הראווה (״סריקה יומית של AI בבריאות״) היא מציין מקום — החלף אותה
בנוסח שתבחר, או הורד אותה לגמרי.
